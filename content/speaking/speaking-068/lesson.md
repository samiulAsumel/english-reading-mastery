## Introduction

[Lesson 68](/lessons/68/) taught you to separate an exception, a
limitation, and a precaution. This drill asks you to explain a rule and
its exception out loud, live, and to name a genuine limitation without
mislabelling it as an exception.

## Shadow the Model

::: shadow rate="0.9"
All containers are inspected on arrival, except those already sealed by
customs. The scanner cannot detect certain organic materials — that's a
limitation, not an exception.
:::

Notice "that's a limitation, not an exception" is spoken firmly and
without hesitation — naming the distinction out loud, live, is exactly
the skill this drill is training.

## Your Turn

::: prompt time="30s"
You'll be given a short rule scenario. When the timer starts, state the
main rule, one genuine exception ("except when..."), and one real
limitation of the system — explicitly labelling which is which.
:::

::: timer seconds="30" label="Explain the rule now — no planning, just speak"
:::

## Model Answer

::: model-answer
There's no single correct wording, but a strong answer states the rule,
carves out one genuine exception with "except," and then explicitly
names a separate limitation — saying out loud that it's a limitation,
not an exception, rather than leaving the listener to work that out.
:::

## Vocabulary in Context

::: vocabulary word="carve out" pos="phrasal verb" register="neutral" meaning="to deliberately exclude a specific case from a general rule (বাদ দেওয়া)" collocation="carve out an exception, carve out from, deliberately carve out" example="The rule applies to all cargo, except that we carve out perishable goods."
:::

::: vocabulary word="constraint" pos="noun" register="formal" meaning="a real limit on what is possible, separate from a rule's exclusions (সীমাবদ্ধতা)" collocation="budget constraint, time constraint, work within constraints" example="The main constraint is that the berth is free only at night."
:::

## Self-Check

::: rubric
- Did you state the main rule before the exception, not the other way around?
- Did you explicitly label your limitation as a limitation, not an exception?
- Did you respond immediately, with no planning pause?
:::
