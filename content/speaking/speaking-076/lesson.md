## Introduction

[Lesson 76](/lessons/76/) taught you to catch framing in a text that's
entirely true. This drill makes you produce it yourself, out loud, then
immediately name your own trick — the fastest way to become immune to
it in other people's writing.

## Shadow the Model

::: shadow rate="0.9"
Container throughput fell by four percent this quarter. Container
throughput suffered a worrying decline this quarter, continuing a
troubling pattern.
:::

Shadow both versions. Notice how much more weight "suffered," "worrying,"
and "troubling pattern" carry, even though the number underneath hasn't
changed at all.

## Your Turn

::: prompt time="30s"
Pick one true, neutral fact. In 30 seconds, say it plainly, then say a
slanted version using only word choice, then name which words did the
slanting.
:::

::: timer seconds="30" label="Speak now — neutral version, slanted version, name the slanting words"
:::

## Record Yourself

::: record label="Record both versions and your explanation, then check nothing false was added in the slanted one."
:::

## Model Answer

::: model-answer
There's no single correct topic — what matters is that both versions
stay true. One natural version: "Wait times averaged six minutes last
month. Customers were left waiting an average of six frustrating
minutes, a clear sign of a service failing to keep up. 'Frustrating,'
'left waiting,' and 'a clear sign of failing' did the slanting — the
number six minutes never changed." Check that your own slanted version
didn't slip in a fact that wasn't actually true.
:::

## Vocabulary in Context

::: vocabulary word="neutral" pos="adjective" register="neutral" meaning="stated plainly, without favoring a particular impression (নিরপেক্ষ)" collocation="neutral tone, remain neutral, neutral wording" example="Say 'the plan lacked approval' for a neutral version."
:::

::: vocabulary word="loaded" pos="adjective" register="neutral" meaning="carrying extra emotional weight beyond its literal meaning (আবেগপূর্ণ/পক্ষপাতমূলক)" collocation="loaded language, loaded word, loaded term" example="'Crackdown' is a loaded word; 'enforcement' is neutral."
:::

## Self-Check

::: rubric
- Did both spoken versions stay strictly true, with nothing false added to the slanted one?
- Did you name the specific slanting words, not just describe the general feeling?
- Did you speak both versions and the explanation without a long planning pause?
:::
