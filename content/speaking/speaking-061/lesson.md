## Introduction

[Lesson 61](/lessons/61/) taught you to catch the moment an author
writes "efficiency is not the same as effectiveness" and track exactly
what divides two familiar words. This drill asks you to build that same
kind of distinction live, out loud, the instant a scenario is given —
no time to plan the sentence first.

## Shadow the Model

::: shadow rate="0.9"
Speed is not the same as responsiveness. Speed measures how quickly one
action completes. Responsiveness measures how quickly the system reacts
when a new request arrives, even under heavy load.
:::

Listen once all the way through without speaking. Notice how "is not
the same as" is said as one smooth unit, almost no pause before the
second clause begins — that's the shape you're aiming for, not a
translated, hesitant version of it.

## Your Turn

::: prompt time="25s"
You'll see two familiar-sounding terms from your own field. When the
timer starts, say: (1) that they are not the same, (2) the precise
difference between them, and (3) one necessary condition connecting
them — all in one continuous explanation, no planning pause. Example
pair: "delay" vs. "downtime."
:::

::: timer seconds="25" label="Explain the distinction now — no planning, just speak"
:::

## Record Yourself

::: record label="Say your explanation, then record it and compare your pace and structure against the model."
:::

## Model Answer

::: model-answer
There's no single correct wording, but a strong answer sounds like:
"Delay is not the same as downtime. Delay means a task takes longer
than expected while the system is still running; downtime means the
system has stopped running entirely. A short delay is necessary before
some systems can be called reliable, but it doesn't guarantee zero
downtime." What matters is that all three parts appeared, in order, with
no long pause between them.
:::

## Vocabulary in Context

::: vocabulary word="boundary" pos="noun" register="formal" meaning="the line marking where one concept ends and another begins (সীমারেখা)" collocation="conceptual boundary, clear boundary, boundary between" example="The boundary between delay and cancellation is where the shipment never leaves."
:::

::: vocabulary word="overlap" pos="noun" register="neutral" meaning="the part two concepts share, rather than being fully separate (সহাবস্থান)" collocation="overlap between, considerable overlap, partial overlap" example="There is some overlap between safety and security."
:::

## Self-Check

::: rubric
- Did you state "X is not the same as Y" immediately, without a long pause first?
- Did your necessary-condition sentence avoid promising the condition alone guarantees the outcome?
- Did the whole explanation come out as one connected piece, not three disconnected fragments?
:::
