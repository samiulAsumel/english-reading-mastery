## Introduction

[Lesson 43](/lessons/43/) taught you to track what each sentence in a
paragraph takes as given and what it adds as new. Speaking that same
flow live is the real test: without a written draft in front of you,
it's very easy to restart the topic every sentence instead of letting
each one hand its new information to the next.

## Shadow the Model

::: shadow rate="0.9"
The terminal installed automatic gate scanners. The scanners cut vehicle
processing time. That drop in processing time reduced congestion during
peak hours.
:::

Listen once all the way through, then shadow it. Notice how "the
scanners" picks up "automatic gate scanners" from the first sentence,
and "that drop" picks up "cut vehicle processing time" from the second —
each sentence opens with what the last one just said.

## Your Turn

::: prompt time="30s"
You'll be given a short operational change to describe. In 30 seconds,
speak three or four connected sentences where each one's subject picks
up the previous sentence's new information (using it, this, that, or a
short summary noun) rather than restarting the topic each time.
:::

::: timer seconds="30" label="Speak your connected sentences now"
:::

## Model Answer

::: model-answer
Given the topic *a company introduced remote scheduling software*:
*"The company introduced remote scheduling software. This software let
managers assign shifts without being on site. That flexibility reduced
the time managers spent traveling between locations."* There is no
single correct chain — what matters is that "this software" and "that
flexibility" each pick up the sentence right before them, so a listener
never has to guess what a pronoun is pointing back to.
:::

## Vocabulary in Context

::: vocabulary word="given information" pos="noun phrase" register="technical" meaning="content already established earlier, usually placed at the start of the next sentence (প্রদত্ত তথ্য)" collocation="place given information first, given and new information, treat as given information" example="In speech, start with given information the listener already knows."
:::

::: vocabulary word="linear progression" pos="noun phrase" register="technical" meaning="a pattern where each sentence's new information becomes the next sentence's given topic (ক্রমিক অগ্রগতি)" collocation="linear progression, follow a linear progression, spoken linear progression" example="Each sentence picks up the last sentence's new information, giving a linear progression."
:::

## Self-Check

::: rubric
- Did each sentence's subject pick up the previous sentence's new information?
- Did you avoid restarting the topic from scratch in the middle sentences?
- Did you speak fluently within the time limit, without long pauses to plan the next link?
- Would a listener never have to guess what a pronoun like "this" or "that" was pointing back to?
:::
