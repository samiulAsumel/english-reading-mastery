## Introduction

[Lesson 35](/lessons/35/) taught you to detect an author's tone and bias
from word choice, sentence structure, and what a passage chooses to
include or leave out. This task makes that mechanism visible from the
inside: you will report one fact twice, keeping the evidence completely
identical while shifting only the tone.

## The Rule, for Writing

::: concept
Tone lives in word choice, not in the facts themselves. To write the
same fact neutrally, use plain reporting verbs (found, reported, shows)
and avoid evaluative adjectives. To write it skeptically, keep every
fact identical but add distancing language (claims, allegedly, has yet
to show) and point to what the evidence doesn't cover. The two versions
should never disagree about what happened — only about how much trust
the wording extends to it.
:::

::: example
**Neutral:** "The company's internal report found that the new software
reduced processing time by fifteen percent." **Skeptical, same fact:**
"The company's own internal report claims the new software reduced
processing time by fifteen percent — a finding that has yet to be
confirmed by anyone outside the company that built the software."
:::

## Your Turn

::: prompt words="2 paragraphs, 40-60 words each" time="20 min"
Choose one real or plausible fact or finding (from work, a report, or
general knowledge). Write it twice: first in a neutral, analytical tone
using plain reporting verbs, then in a skeptical tone using distancing
language and a note about what the evidence doesn't cover. Do not change
or add any fact between the two versions — only the tone should shift.
:::

::: draft placeholder="Neutral: [Source] found/reported that .../ Skeptical: [Source] claims that ..., though this has not yet been ..."
:::

## Model Answer

::: model-answer
**Neutral:** A survey of the port's trucking partners found that the new
online booking slot system reduced average gate waiting time by twenty
minutes. Drivers using the system reported fewer unplanned delays during
peak hours.

**Skeptical:** The port claims its new online booking slot system cut
average gate waiting time by twenty minutes, based on a survey it
conducted itself. No independent study has yet confirmed the figure, and
drivers who didn't adopt the system weren't included in the results.
:::

## Self-Check

::: rubric
- Did both versions report the exact same underlying fact, with nothing added or removed?
- Does your neutral version use plain reporting verbs, free of evaluative adjectives?
- Does your skeptical version use genuine distancing language and name a real limit in the evidence?
- Did you write this directly in English, without translating from Bangla first?
:::
