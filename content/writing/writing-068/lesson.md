## Introduction

[Lesson 68](/lessons/68/) taught you to separate a genuine exception
(excluded from a rule) from a limitation (a real constraint on
capability) and a precaution ("in case," preparing for something that
may never happen). This task asks you to write a rule paragraph that
keeps all three distinct.

## The Rule, for Writing

::: concept
State the main rule plainly. Add one true exception ("except when...")
that carves a known case out of the rule. Add one limitation ("the
system cannot..." — a real constraint, not an exclusion). If relevant,
add a precaution ("in case...") for something that might happen, not
something that already applies.
:::

::: example
*All containers are inspected on arrival, except those already sealed
by customs. The scanner cannot detect certain organic materials — a
genuine limitation, not an exception. Staff carry a manual override
device in case the automated system fails.*
:::

## Your Turn

::: prompt words="80-120 words" time="20 min"
Write a short rule paragraph for a real or realistic process. Include:
one main rule, one true exception ("except when..."), and one genuine
limitation of the system or process (something it simply cannot do,
not something excluded from the rule). Optionally add a precaution.
:::

::: draft placeholder="[Main rule]. Except when... / However, [the system/process] cannot... (this is a limitation, not an exception)"
:::

## Vocabulary in Context

::: vocabulary word="limitation" pos="noun" meaning="a real constraint on what something can do, distinct from an excluded case — সীমাবদ্ধতা" example="Detecting counterfeit goods is a limitation of the current scanner, not an exception in the policy."
:::

::: vocabulary word="precaution" pos="noun" meaning="a preparation for something that might happen, not something that already applies — সতর্কতামূলক ব্যবস্থা" example="Staff keep a backup generator running as a precaution against power loss."
:::

## Model Answer

::: model-answer
All export documents are verified electronically before release, except
when the exporting country has no digital verification system in
place, in which case a manual check applies instead. The verification
software cannot currently read handwritten annotations reliably — a
genuine limitation, not something the policy excludes on purpose. As a
precaution, staff also keep a printed backup of every verified document
in case the digital system goes offline unexpectedly.
:::

## Self-Check

::: rubric
- Did your exception carve out a specific, known case rather than restating the limitation?
- Did your limitation describe something the system genuinely cannot do, not an excluded case?
- If you included a precaution, did it prepare for something that might happen, not something already true?
- Did you write directly in English, without composing the passage in Bangla first?
:::
