## Introduction

[Lesson 42](/lessons/42/) taught you to find a dense sentence's main
clause first, then see how subordinate and embedded clauses hang off it.
Building one yourself is a different discipline: you have to keep track,
while writing, of which clause is actually carrying the sentence's main
point and which are only supporting it.

## Main, Subordinate, Embedded

::: concept
A **main clause** can stand alone. A **subordinate clause** (often
starting *because, although, when, since*) cannot stand alone and
depends on the main clause. An **embedded** clause — often a relative
clause — sits inside another clause, modifying one of its nouns.
:::

::: example
**Main + subordinate:** *The system failed because the server
overheated.* **Adding an embedded relative clause inside the
subordinate clause:** *The system failed because the server, which had
not been serviced in months, overheated.*
:::

## Your Turn

::: prompt words="1 sentence" time="20 min"
Write one sentence with a main clause, a subordinate clause attached to
it (using because, although, when, or since), and a relative clause
embedded inside the subordinate clause (modifying one of its nouns).
Then write the main clause alone underneath, to prove it can stand by
itself.
:::

## Vocabulary in Context

:::

::: vocabulary word="embedded clause" pos="noun phrase" register="technical" meaning="a clause placed inside another clause, usually modifying one of its nouns (অন্তর্ভুক্ত বাক্যাংশ)" collocation="embedded clause, place an embedded clause, embedded relative clause" example="In 'The report that the auditor wrote was long', 'that the auditor wrote' is an embedded clause."
:::

## Model Answer

::: model-answer
*The terminal delayed the shipment because the crane, which had been
flagged for maintenance the previous week, broke down during loading.*
Main clause alone: *The terminal delayed the shipment.* Subordinate
clause: *because the crane broke down during loading.* Embedded relative
clause: *which had been flagged for maintenance the previous week*
(modifying "the crane").
:::

## Self-Check

::: rubric
- Does your main clause make a complete, grammatical sentence on its own?
- Is your subordinate clause correctly attached with because/although/when/since?
- Does your embedded relative clause clearly modify one specific noun, without ambiguity?
- Is the finished sentence grammatical all the way through, not just in pieces?
:::
