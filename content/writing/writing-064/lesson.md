## Introduction

[Lesson 64](/lessons/64/) taught you that "should," "must," "may," and
"could" each do a different job — obligation, permission, possibility,
recommendation. This task asks you to write a short passage that uses
each modal deliberately, not interchangeably.

## The Rule, for Writing

::: concept
Use "must" for obligation, "should" for a recommendation short of
obligation, "may" for permission or possibility, and "could" for a
weaker possibility or option. State one fact plainly (no modal), then
one rule with "must," then one recommendation with "should," and name
at least one exception using "unless" or "except."
:::

::: example
*All shipments must be logged before leaving the warehouse. Drivers
should confirm the delivery address by phone before departure, unless
the customer has already confirmed it in writing. Drivers may take an
alternate route if the main road is closed.*
:::

## Your Turn

::: prompt words="80-120 words" time="20 min"
Write a short policy passage for a real or realistic workplace
scenario. Include: one plain fact (no modal), one obligation ("must"),
one recommendation ("should"), one permission or possibility ("may" or
"could"), and one stated exception ("unless" or "except").
:::

::: draft placeholder="[Fact, no modal]. [Rule] must... / [Recommendation] should..., unless... / [Permission] may..."
:::

## Vocabulary in Context

::: vocabulary word="obligation" pos="noun" register="formal" meaning="something a rule requires, not merely suggests (বাধ্যবাধকতা)" collocation="legal obligation, meet an obligation, obligation to" example="The carrier has an obligation to notify the consignee within a day."
:::

::: vocabulary word="exception" pos="noun" register="neutral" meaning="a stated case where the general rule does not apply (ব্যতিক্রম)" collocation="with the exception of, make an exception, notable exception" example="With one exception, all berths met the target."
:::

## Model Answer

::: model-answer
All incoming containers are scanned automatically on arrival. Staff
must log any scanning error before the container leaves the yard. Staff
should also photograph visible damage at intake, unless the container
is being transferred directly to another vessel without unloading. In
urgent cases, a supervisor may authorise release before the full
paperwork is complete, though this remains the exception rather than
the norm.
:::

## Self-Check

::: rubric
- Did you include one plain fact stated without a modal verb?
- Did "must" and "should" mark genuinely different strengths, not used interchangeably?
- Did you state at least one exception using "unless" or "except"?
- Did you write directly in English, without composing the passage in Bangla first?
:::
