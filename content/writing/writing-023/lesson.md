## Introduction

[Lesson 23](/lessons/23/) taught you to trace how a skilled writer keeps
one idea alive across a paragraph — reaching for a pronoun, a *this/
these* phrase, or a synonym instead of repeating the same noun five
times. Reading that chain is one skill; building your own is the one
that actually makes your writing sound fluent instead of mechanical.

## The Rule, for Writing

::: concept
Name your topic once, directly, in your first sentence. After that,
never use the exact same noun again for it — reach instead for a
pronoun (*it, they*), a summary phrase (*this problem, these changes*),
or a synonym (*the system* → *the platform*). Each renaming is a link in
the same chain, not a new idea.
:::

::: example
**The port installed a new gate-scanning system last month.** *It*
processes containers in half the time the old scanner did. *This
upgrade* has already cut truck queues significantly, and drivers have
noticed *the change* almost immediately.
:::

## Your Turn

::: prompt words="4 sentences" time="12 min"
Write four connected sentences about one topic of your choice — your
workplace, a habit, a piece of technology you use. Sentence 1 names the
topic directly. In sentences 2-4, refer back to it using a pronoun, a
*this/these + noun* phrase, and a synonym — one device per sentence, and
never the exact same noun twice.
:::

::: draft placeholder="1. [Topic, named directly] / 2. It ... / 3. This [noun] ... / 4. [Synonym] ..."
:::

## Vocabulary in Context

::: vocabulary word="upgrade" pos="noun" register="neutral" meaning="an improvement to an existing system (উন্নতিসাধন)" collocation="system upgrade, major upgrade, upgrade to" example="The terminal's upgrade to a new operating system took a weekend."
:::

::: vocabulary word="thread" pos="noun" register="neutral" meaning="a single idea or theme that runs through a longer piece of writing (সূত্র/ধারাবাহিকতা)" collocation="a thread of, follow the thread, thread through" example="A single thread, reliability, runs through the whole report."
:::

## Model Answer

::: model-answer
I started learning to cook last year. It felt overwhelming at first,
since I'd never planned a full meal before. This new habit has slowly
become one of my favorite parts of the week, and the routine now feels
completely natural rather than stressful.
:::

## Self-Check

::: rubric
- Does sentence 1 name the topic directly, with no pronoun yet?
- Do sentences 2-4 each use a different device (pronoun, this/these phrase, synonym) rather than repeating one trick?
- Did you avoid using the exact same noun for the topic more than once?
- Does the paragraph read as one thread when you read it aloud, not four separate facts?
:::
