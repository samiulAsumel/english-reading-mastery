## Introduction

[Lesson 2](/lessons/2/) taught you to find a long sentence's skeleton by
stripping decoration away. This task builds the skeleton from the other
direction: start with a small, correct core sentence, then add
decoration to it on purpose, one modifier at a time, without losing
the core underneath.

## Building Out From a Core

::: concept
Start with the smallest correct core: **The manager reviewed the
report.** Now add one modifier at a time, and notice the core never
changes: an adjective — **The experienced manager reviewed the
report.** — an adverb — **The experienced manager carefully reviewed the
report.** — a prepositional phrase — **The experienced manager carefully
reviewed the financial report yesterday.** Four additions, one
unchanged core: *manager reviewed report.*
:::

::: example
**Core:** Researchers study behavior.

**Wrapped:** Experienced researchers carefully study human behavior in
controlled conditions.

Modifiers added: *experienced* (adjective), *carefully* (adverb),
*human* (adjective), *in controlled conditions* (prepositional phrase)
— and the core sentence hiding inside is still exactly the same three
words.
:::

## Your Turn

::: prompt words="1 core sentence + 3 wrapped versions" time="12 min"
Write one short core sentence (Subject + Verb + Object) about your work
or studies. Then rewrite it three times, adding one more modifier each
time: first an adjective, then an adverb, then a prepositional phrase —
keeping all the earlier additions in place.
:::

::: draft placeholder="Core: The team finished the report. / +adjective: .../ +adverb: .../ +prepositional phrase: ..."
:::

## Vocabulary in Context

::: vocabulary word="modifier" pos="noun" meaning="a word or phrase that adds detail to another word without changing the sentence's core — পরিবর্তক" example="Carefully is a modifier describing how the manager reviewed the report."
:::

::: vocabulary word="decoration" pos="noun" meaning="here, used informally for the modifiers wrapped around a sentence's core — অলঙ্করণ" example="Strip away the decoration and the core sentence is often quite short."
:::

## Model Answer

::: model-answer
Core: The team finished the report.

+ adjective: The tired team finished the report.

+ adverb: The tired team quickly finished the report.

+ prepositional phrase: The tired team quickly finished the report
before the deadline.
:::

## Self-Check

::: rubric
- Does the same three-word core (Subject, Verb, Object) survive unchanged through all four versions?
- Did you add exactly one new modifier at each step, rather than several at once?
- Could you point to the adjective, the adverb, and the prepositional phrase separately in your final sentence?
:::
